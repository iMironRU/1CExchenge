Реестр обменов 1С

Из какой типовой конфигурации в какую есть синхронизация (обмен данными) и переход (перенос данных при смене программы). Связи найдены в полных поставках: в файлах правил КД2 и в коде конфигурации (планы обмена, EnterpriseData, помощники перехода).

Ссинхронизация Ппереход строка — откуда, столбец — куда; цифра — число связей в ячейке; клик по названию — все связи конфигурации На телефоне удобнее вкладка «Пара».

Каждая связь отнесена к учётной задаче (по семействам конфигураций сторон), механизму, направлению (двусторонняя — есть связь и в обратную сторону) и актуальности (обе стороны — последние редакции по каталогу Апдейкона). Клик по паре открывает её в матрице.

Какие объекты «ездят» между конфигурациями — по правилам КД2 (ПВД + ПКО) и правилам EnterpriseData (отправка одной стороны ∩ получение другой по объекту формата). Объект ищется по имени метаданных в любой из сторон.

Версии формата EnterpriseData, которые конфигурация объявляет для обмена (ВерсииФормата.Вставить(…) в коде CF). Обмен через универсальный формат возможен, когда у пары есть общая версия; стороны договариваются о максимальной общей.

Максимальная общая версия

Реестр строится по полным поставкам из каталога шаблонов. Чем больше поставок разобрано, тем полнее матрица. Ссылки ведут на страницы файлов releases.1c.ru (из API Апдейкона): портал пускает под учётной записью ИТС с подпиской, а полные дистрибутивы части конфигураций отдаёт только после одноразового кода, поэтому их качают вручную в браузере. Пакеты перехода с других конфигураций перечислены под каждой конфигурацией и уже учтены в матрице.
